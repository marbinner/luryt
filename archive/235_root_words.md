## Design Notes for Version 2.0

### 1. **Root Disambiguation**
The original "light" has been split into two roots:
- **lum-** (light₁): brightness, illumination → enables lum-ness (brightness), lum-ify (illuminate)
- **lev-** (light₂): not heavy, weightless → enables lev-ness (lightness), lev-ify (lighten weight)

This resolves 5 ambiguity bugs in the derivational system.

### 2. **Coverage Improvements**
The 35 new roots specifically address the 229 "missing root" bugs identified in testing:
- **10 Cognitive roots**: mind, idea, mood, feel, time, true, hope, simple, wish, concept
- **8 Action roots**: do, work, build, talk, task, cut, wash, bake
- **2 Spatial roots**: place, home
- **4 Social roots**: status, career, child, value
- **2 Nature roots**: wind, war
- **2 Communication roots**: voice, welcome
- **2 Property roots**: heat, free

### 3. **Metaphor Enablement**
These additions specifically enable critical metaphors that were blocked:
- **UP/DOWN IS GOOD/BAD**: Now possible with "mood" root
- **MIND IS CONTAINER**: Now possible with "mind" root
- **IDEAS ARE OBJECTS**: Now possible with "idea" root
- **TIME IS MOTION**: Now possible with "time" root
- **BUILDING IS CREATING**: Now possible with "build" root
- **WAR IS ARGUMENT**: Now possible with "war" root

### 4. **Productivity Analysis**
**Theoretical vocabulary expansion:**
- Original 200 roots → ~10,000 derivable words
- New 235 roots → ~12,000+ derivable words
- **20% increase in generative capacity**

### 5. **Learning Pathway Impact**
Stage 1 (Basic):
- Was: 200 roots + 20 affixes = 220 items
- Now: 235 roots + 20 affixes = 255 items
- **Increase: 35 items (~16% more)**

This is manageable and worth the improved expressiveness.
