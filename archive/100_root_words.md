## Design Notes for Your Conlang

### 1. **Spatial Case System**
Consider grammatical cases based on the container metaphor:
- **Inessive** (in/inside): for states, emotions
- **Elative** (out of): for changes
- **Illative** (into): for entering states
- **Adessive** (at/on): for locations, topics

### 2. **Vertical Aspect System**
Use vertical metaphors for:
- **Upward aspect**: improvement, increase, happiness
- **Downward aspect**: deterioration, decrease, sadness
- **Level aspect**: stability, continuation

### 3. **Temperature Gradience**
Build a system for emotional intensity:
- Cold → Cool → Warm → Hot → Burning

### 4. **Weight as Grammatical Marking**
Consider marking importance or difficulty:
- Heavy prefix/suffix for important or difficult
- Light prefix/suffix for trivial or easy

### 5. **Path/Journey Constructions**
Create serial verb constructions for processes:
- "He walked-to success" = He achieved success
- "We journey-through difficulty" = We experience hardship

### 6. **Body-Part Compounding**
Use body parts productively:
- heart-hold = remember (emotionally)
- eye-catch = notice
- head-pain = worry/problem
- hand-give = help

## Suggested Derivation Patterns

From these 200 roots, you can derive:

### Adjectives → Abstract Nouns
- heavy → heaviness → importance
- high → height → status/power
- warm → warmth → affection

### Spatial → Temporal
- front → future
- back → past
- path → process

### Physical → Mental
- see → understand
- grasp (hold) → comprehend
- dark → ignorant
- light → intelligent

### Physical → Social
- close → intimate/friendly
- far → estranged
- high → superior
- low → inferior

### Body → Emotion
- heart → love/emotion
- head → thought/reason
- face → honor/dignity
- hand → help/action

### Texture → Character (New from Tier 4)
